Terraform Script Generator

Pick a platform, pick what you are building — EC2 with a security group, a versioned S3 bucket, a VPC baseline, RDS Postgres, a vSphere VM from a template — fill in its parameters and get ready-to-paste HCL. Every resource type is checked against the committed provider catalog first. The Map tab on the same page is the reference: which resource does which job, per cloud and per domain.

Run it

The operational glue: what you write once something is live.

Script Generator

PowerShell, Python, Bash and Windows batch. A catalogue of 522 commands you can search by what you are trying to do, each with the thing about it that is not in the help — and a builder that wraps any of them in strict mode, logging, a dry run and a loop. Every script says what it needs, how to make it report instead of act, and how to undo it, in its own header. No credential is ever written into one.

Ready

Splunk App Generator

Fifty-six deployable Splunk apps across every tier: onboarding for the network, VCF and VM estate this toolkit builds, CIM-mapped add-ons, clustering, security, SmartStore, heavy forwarder sources, Edge Processor and OpenTelemetry, and Splunk Cloud through ACS. Each app says which tier it goes on and how it is activated; every script is a dry run until told otherwise.

ArchPad

A text and code editor with everything Notepad++ does: tabs, syntax highlighting for forty-odd languages, column mode, find and replace with regular expressions, find in files, compare, line operations, macros and encodings — plus the toolkit's tools and the network calculator in its menus.
